# Job Application Tracker Web App

A full-stack web application that allows users to track job applications.

## Features
- User registration and login
- Add job applications
- Edit job information
- Delete job entries
- Dynamic job table display
- SQLite database storage

## Tech Stack
- Node.js
- Express.js
- SQLite
- HTML
- CSS
- JavaScript

## How to Run
npm install
npm run dev
Open http://localhost:3000
